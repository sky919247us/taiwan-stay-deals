# 查價任務指示（第 3 版）

## 任務

CSV 每一列是一家台灣旅宿。請查出它在**指定日期**的**平日雙人房**每晚最低房價。

日期已寫在每一列，固定 **2026-09-01（週二）入住、2026-09-02 退房、2 位成人**。
這是台灣國旅補助適用的平日，全部用同一天查，價格才能互相比較。

從 **batch_03 開始**（batch_01、02 已完成，結果已記錄）。**一次做一批**。

batch_03～08 各一家，5 家裡有 3 家查得到數字 —— 只是其中 2 個是**包棟價**：

|---|---|---|---|

**如果前兩批你把這種情況判成「當日售完」，那你的判斷是對的**（那些數字確實不該填），

## 欄位怎麼填

| 欄位 | 填什麼 |
|---|---|
| `平日雙人房價` | 只填阿拉伯數字，不要逗號、不要「元」。**只有確定是雙人房才填**，否則留空 |
| `房型名稱` | 該價格對應的房型，例如「標準雙人房」「一大床」。**填了價格就一定要填** |
| `來源平台` | Booking.com、Agoda、Trip.com、易遊網、官網、Google… |
| `結果` | 五選一，見下表，**每一列都要填** |
| `查核日期` | 你查詢當天的日期 |
| `備註` | **見下方，這欄現在很重要** |

### `結果` 的五個選項

| 值 | 什麼時候用 |
|---|---|
| `已查到` | 有填雙人房價格 |
| `僅有其他房型` | **查得到這家、也看得到價格，但只有包棟／四人房／單人房**。此時**必須在備註寫下看到的數字與房型**，例如「包棟 8000」「四人房 3200」 |
| `平台無此旅宿` | 訂房平台上完全找不到這家（搜尋結果只有附近其他旅宿） |
| `當日售完` | **找得到這家、平台上確實顯示該日無空房**才用這個。不確定就用 `平台無此旅宿` |
| `查詢失敗` | 網頁打不開、被擋、其他技術原因 |

`平台無此旅宿` 與 `當日售完` 的差別：前者是搜尋結果裡根本沒有這家，後者是有這家
但那天訂不到。前兩批有 73 筆標成「當日售完」，我實際抽查兩家
（彰化華宿文旅、羅東好民宿），**Google 飯店搜尋根本沒有列出它們** —— 那應該是
`平台無此旅宿`。分不清楚時，一律用 `平台無此旅宿`。

## 什麼不算雙人房價（看到就填 `僅有其他房型`，並把數字寫進備註）

- **包棟、整棟出租**（台灣民宿最常見的陷阱，價格通常是雙人房的 3～5 倍）
- 四人房、三人房、家庭房、通鋪
- 汽車旅館的「休息 3 小時」時段價
- 升等加價（「加 999 元升等豪華房」的 999）
- 早鳥折扣、優惠折抵金額
- 兩晚以上的總價

## 合理性檢查

每列都有 `合理價格下限` 與 `合理價格上限`（依業者自報的定價區間算出）。

**查到的數字超出這個範圍，幾乎一定是包棟或大房型。** 這種情況請填
`僅有其他房型`＋備註寫數字，**不要填進「平日雙人房價」**。

伯爵民宿就是例子：定價 4,500，查到 10,851，超出上限一倍多。

---

## 不確定就留空

寧可少填，不要填錯。這份資料會直接顯示給要訂房的民眾看，錯的價格比沒有價格更糟。

---

## 怎麼查

每列都附 `Google地圖` 直達連結，點開就是那一家，Google 會列出各訂房平台報價。
另有 `官網` 與 `電話` 可交叉確認。
